# skillDB

skillDB is a fully local, privacy-first resume and skills management platform.

It acts as a personal career vault, storing all your experiences, projects, education, and skills. When you find a job you want to apply for, simply paste the job description, and skillDB uses AI (via your own local API keys) to generate a highly tailored, ATS-friendly resume.

## Features

- **Local Vault**: All your data is stored locally in your browser. No databases, no tracking.
- **AI Resume Generation**: Contextualizes your profile data against a target job description to build a custom resume.
- **Multiple Providers**: Bring your own API key for Gemini, Groq (and more to come).
- **Export & Import**: Full data portability via JSON export/import.
- **ATS Friendly Templates**: Clean, parsed resume output designed for maximum compatibility with Applicant Tracking Systems.
- **Light & Dark Mode**: A beautiful, colorful interface inspired by shadcn UI.

## Getting Started

1. Add your API keys in the Settings page.
2. Fill out your Profile with your work history, projects, and skills.
3. Go to the Resume Builder, paste a job description, and generate your tailored resume!
4. Print or save as PDF.
